# Blinkenbar media

- `cm5-inspired-study.png`: preserved original CM-5-inspired artwork, generated with OpenAI's image tool through ChatGPT OAuth. Illustrative, not a historical photograph or plugin screenshot.
- `blinkenbar-prodyn-hero.png`: approved header composition with the artwork, Blinkenbar title, and actual ProDyn.ai signature. Essential text is inset for the catalog's center crop.
- `blinkenbar-spectrum.png`: Ember, Ion and Matrix panels composed from the existing actual-plugin captures.
- Other panel captures and the GIF use the real plugin in an isolated browser host, an aggregate system-counter sample and an idle agent. No agent activity was injected.

Header and spectrum typography use Oxanium and Departure Mono (SIL Open Font License). ProDyn branding is used with the owner's approval; the project license does not grant rights to impersonate the brand.

The CM-5 is the visual inspiration, not an affiliation with Thinking Machines Corporation. Reference: https://people.csail.mit.edu/bradley/cm5/
