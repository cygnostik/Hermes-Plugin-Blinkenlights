# Blinkenbar presentation notes

## Description

A supercomputer-style light panel for Hermes Desktop, driven by aggregate system counters and live agent activity.

## Visual direction

Preserve the dense light banks, black instrument field, restrained glow and tiny, subdued labels. CM-5-style supercomputer panels are the inspiration, not a claim of hardware emulation. Motion is central: ambient patterns remain alive while actual work changes the activity signatures. The panel should reward familiarity with its rhythms rather than require users to read every light as a meter.

The canvas is passive. Keep actual presentation controls separate from the light field. Do not manufacture task activity for a product capture.

## Public claims

Use the shipped [README](README.md) as the feature and privacy reference. Describe disk fallback as an activity proxy, GPU sampling as optional Windows NVML, and measurements as belonging to the backend host. Do not claim benchmarking, task progress percentages, anomaly detection, audit history, certification, universal platform verification or endorsement by Nous Research.

## Catalog submission

The [Hermes plugin catalog](https://hermes-agent.nousresearch.com/docs/plugins) accepts maintainer-reviewed pull requests adding a file under `plugin-catalog/` in the [Hermes repository](https://github.com/NousResearch/hermes-agent). Follow its [current admission policy](https://github.com/NousResearch/hermes-agent/blob/main/plugin-catalog/README.md).

Use the public repository URL, the actual release version, and the exact reviewed commit. Declare the desktop category and community tier; the Python entrypoint currently registers no tools, hooks or middleware and requires no environment variables. Do not infer a minimum Hermes version. Pin the catalog image to the same commit as the code.

Publishing a repository does not make it a catalog entry. Admission and future updates require maintainer review; each update uses a new commit-pin PR.
